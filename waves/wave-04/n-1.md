Marks: [ran] = exact integer run of mine tonight (my own code, files in `n-1/`), [derived] = by hand tonight, checked by nobody,
[read] = from h-5.md, h-8.md or the web, [guess]. Gate count everywhere: **(G)**, a gate is any a*u + b*v, scalings free.

**FIRST LINE. Both hand proofs stand. Neither gives a circuit, and both say "not linear" for the class they fence: the order stays
N log2 N inside each class. I found no failing case. The one unfinished case of Proposition A (the flipped hub) I closed by hand
for a circuit with ONE over-limit wire at every size; for several such hubs it is still open, but it cannot change the order:
without it the class still needs at least (2/3) N log2 N gates.**

Words, as in the two reports. N = 2^k points. A *wire* is a linear form the program holds, up to a scalar. s, s' = its number of
non-zeros written in the inputs and in the outputs; always s*s' >= N. *Tight*: s*s' = N (then s = 2^d and d is its *level*).
*Over the limit*: s*s' > N. V = number of over-limit wires of a circuit, G = its number of gates.
*Entangled on bit i*: the wire, read as a table with one index per address bit, is not (a 2-vector on bit i) times (a rest).
*Width* e(w) = number of bits the wire is entangled on. K(i,t) = the forms that are (1,t) on bit i times anything, t = +1 or -1.
A gate w = a*u + b*v is a *birth at (i,t)* when w is in K(i,t) and both parents are outside; c(g) = its number of births.
*Tight line* = all combinations of two tight wires. *Hub* = an over-limit wire on a tight line whose two tight wires are two
levels apart (the 4-point wire (1,1,1,-1) on four "cells" p1..p4 of level b, with s*s' = 4N when it is *full*).
*Jumper* = a gate (hub, cell) -> tight wire two levels above the cell.

## 1. The claims, stated exactly

**h-5.** Lemma 1: for each of the 2k pairs (i,t) a program needs N/2 births, so the births of all gates sum to at least N log2 N.
Lemma 2: c(g) <= max(1, e(u), e(v)). Theorem: if every wire has width at most b in one fixed labelling of the address bits,
G >= N log2 N / b.
**h-8.** Lemmas 2 and 3: a non-tight wire that lies on two different tight lines has s*s' <= 6.25 N and neither line spans 3 or
more levels. Proposition A: if no gate has two over-limit wires among its three wires, G >= N log2 N - V. Its proof is complete
for hubs made from two tight wires one level up and for hubs made "by a flip" (hub = tight wire w4 of level b+2 minus twice one
cell) when b = 0; for a flip with b >= 1 it gives only N log2 N - 2 per such hub, and h-8 closed that at 8 points by cases.

## 4. The unfinished flip case [derived, by me, unchecked]

Setting: hub h = w4 - 2 p4, with w4 = p1 + p2 + p3 + p4 tight of level b+2, b >= 1, three jumpers h - 2 p_i -> w_i.
T = the tight wires of level b+1 made by gates that go up. The count of h-8 gives N log2 N - 2 exactly when w1, w2, w3 are
independent modulo the span of T, no gate is wasted, and every threshold is crossed exactly N times.

**Parity lemma.** Under those three conditions the level-b wires the circuit holds are exactly N and form a basis B. Tight
wires written with entries 0, +1, -1 obey: a level-(b+1) wire made upward is +-r +- r' (two wires of B) or +-2r +- q (q an
earlier level-(b+1) wire with the same support). So every wire of T has whole-number coordinates in B with exactly two odd
ones, and the chain that made it starts at a wire +-r +- r' with those two. The same one level up: w4 is, modulo 2, the sum of
two wires of T. But w4 = p1 + p2 + p3 + p4 and the coordinates in B are unique, so the four odd coordinates are p1..p4: the
two chains start at wires +-(p_i +- p_j) and +-(p_k +- p_l), both in T. Their span is a plane inside span(p1..p4) =
span(w1..w4); a plane meets the 3-dimensional span(w1, w2, w3). So w1, w2, w3 are NOT independent modulo T. Contradiction.
With two jumpers instead of three the level count alone already gives N log2 N - 1.

**Result.** A circuit whose only over-limit wire is a flipped hub has G >= N log2 N - 1 at every N and every b: Proposition A
holds for V = 1 at all sizes (h-8 had 8 points). **Still open:** several hubs at once, when a flipped hub's parent w4, or a
wire between it and level b, was itself made by another hub's jumper; then the coordinates need not be whole numbers and my
argument does not apply. What is proved for all circuits of the class is G >= N log2 N - V - F, F = number of flipped full
hubs with b >= 1 and three jumpers.

## 5. Known or not

The frame is known: a quantity that the transform must raise by N log2 N and that one gate can raise only a little.
Morgenstern 1973 does it with a determinant for bounded coefficients; Ailon (arXiv 1305.4745, 2013) with a matrix entropy for
2x2 unitary gates; Ailon (arXiv 1403.1307, 2014) proves at least (n log n)/R gates when every partial product of the gates has
condition number at most R, and the follow-up (Ailon and Yehuda, arXiv 1609.03278, 2016) reads this as "a speed-up is at most
proportional to the condition number" [read, abstracts only]. h-8's s*s' is the support-size cousin of that entropy; h-5's
births are a rank count per address bit. The two exact statements (width at most b; no gate with two over-limit wires) I did
not find in two searches; that is a short search, not a claim of novelty.
What the known theory predicts for "linear or not": linear size needs a computation whose condition number grows like log N.
Tonight's two lemmas say the same thing in wire language: gates that read a wire of width about log2 N, and gates with two
over-limit wires.

## 6. What it gives in the user's terms

No circuit, no saving exponent. Two fences, each with saving exponent 0 (a constant factor only):
- wires of width at most b in one labelling: G >= N log2 N / b. At b = log2 N this is only N, and a width-k wire costs one
  gate, so it is a necessary shape for linear size, not a wall. Width also depends on the labelling (x0 + x7 has width 3 in
  the standard bits and 0 after a relabelling [read, h-5]).
- over-limit wires that never meet in a gate: **(2/3) N log2 N <= G**, and e2-0's family reaches (3/4) N log2 N + N/4.
  [derived] Every hub needs its own gate plus at least one reader, a flipped hub its own gate plus three jumpers, so
  V + F <= G/2, and G >= N log2 N - V - F gives the 2/3. This holds whether or not the flip case is ever closed.
  If hubs with one jumper are shown to save nothing and the flip case closes, the same tally gives (3/4) N log2 N, which
  would make e2-0's constant exact for the class [guess].
So any circuit below (2/3) N log2 N at any size must contain a gate with two over-limit wires. g-1's 19 at 8 points does.
